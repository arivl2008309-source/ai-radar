# AI 雷达 (AI Radar v6)

一个聚合 AI 资讯、行业应用、arXiv 论文、社区热帖的 Web 应用，带智能过滤、自动更新、响应式移动端适配。

## 访问方式

### 公网版（手机/任意设备，推荐随时随地访问）

```
https://981e58103de84576b45ff610a98d8107.app.codebuddy.work
```

- 部署在 CloudStudio，手机浏览器直接打开即可
- 数据经公共 CORS 代理（`proxy.cors.sh`，故障自动切 `allorigins`）直连上游，**无需本地后端**
- 兼容手机 VPN 环境（标准 HTTPS 请求）
- 可"添加到主屏幕"当 App 用（已配 PWA manifest）

### 本地版（本机运行）

**方式一：双击启动器**
- 双击 `start.bat` → 自动启动服务并在浏览器打开

**方式二：手动**
```bash
cd 本目录
python proxy.py 8787
# 浏览器访问 http://localhost:8787/
```

```
http://localhost:8787/
```

> 本地版走 `proxy.py` 代理进程（双击 start.bat 自动管理）。

## 双模式架构

前端自动识别运行环境：
- `localhost` / `127.0.0.1` → 本地模式，走 `proxy.py`（`/api/*`）
- 其他域名（CloudStudio 等）→ 公网模式，走公共 CORS 代理直连上游

同一份代码，两种部署，无需维护两套。

## 功能

- **4 个标签页**：AI 资讯 / 行业应用 / 社区热帖(HN) / arXiv 论文
- **智能过滤**：去垃圾、去重、仅优质（状态栏显示滤除统计）
- **行业场景**：医疗、金融、制造、零售、教育、汽车、政务、文娱、农业、能源、机器人、法律、网安、科研 + 全部动态
- **自动更新**：每 30 分钟静默刷新；切回页面超 5 分钟自动刷新；顶部 🔄 按钮手动刷新
- **最后更新时间**：标题下方时间戳，绿点=新鲜 / 黄点=过期
- **响应式**：桌面 4 列 / 平板 2 列 / 手机单列全宽，44px 触控区，适配 iPhone 安全区
- **深浅色主题**：跟随系统，可手动切换
- **收藏 / 已读**：localStorage 持久化

## 技术说明

- 纯前端（HTML/CSS/JS，无构建）+ 零依赖 Python 代理
- 代理解决 AI HOT / arXiv / Hacker News 的跨域(CORS)问题
- AI HOT 公开 API 无 CORS 头，故必须经代理转发
- 数据来源：AI HOT · arXiv · Hacker News（仅供学习参考，版权归原作者）
